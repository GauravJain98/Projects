# Projects

This repository contains a collection of Terraform-based infrastructure projects focused on secure database management and microservice deployment automation.

## 📁 Project Overview

### [Terraform-managed PostgreSQL Access Control](./Terraform-managed%20PostgreSQL%20access%20control/)
Infrastructure-as-code solution for managing PostgreSQL database access controls using Terraform. Provides automated user management, role-based permissions, and security compliance.

### [Terraform-Managed PostgreSQL Secure Git-Managed Query Runner](./Terraform-managed%20PostgreSQL%20secure%20Git-managed%20query%20runner/)
A secure, Git-integrated query execution system for PostgreSQL databases. Features version-controlled query management with audit trails and automated deployment pipelines.

### [YAML-Specified Microservice Creation System](./YAML-specified%20microservice%20creation%20system/)
Automated microservice scaffolding and deployment system using YAML configuration files. Streamlines the creation of containerized services with consistent infrastructure patterns.
